#  Fruit Sales & Inventory Analysis Dashboard

An interactive data visualization dashboard designed to analyze fruit sales, explore product performance, and understand inventory trends to support data-driven business decisions.

## Short Description 

The **Fruit Sales & Inventory Analysis Dashboard** is a data analytics project that presents sales and inventory information in a clear, visual format. It helps users explore fruit-wise sales performance, identify sales patterns, and understand inventory-related trends. The dashboard aims to simplify data analysis and support better business planning and inventory management.

##  Tech Stack

The project uses the following tools and technologies, as applicable:

- **📊 Microsoft Power BI** – Used to build the dashboard and create data visualizations.
- **📂 Microsoft Excel** – Used as the source dataset.
- **🔄 Power Query** – Used for data cleaning and transformation, if applied.
- **🧠 DAX (Data Analysis Expressions)** – Used for calculated measures and KPIs, if applied.
- **📁 File Formats** – Excel (`.xlsx`) for the dataset and Power BI (`.pbix`) for the dashboard.

##  Data Source

**Source:** Fruit Sales and Inventory dataset in Excel format.

The dataset contains sales and inventory-related information about fruit products. It serves as the foundation for exploring sales performance, comparing products, and understanding inventory trends.

## Features

### Business Problem

Businesses need to understand product sales and inventory levels to plan stock efficiently and make informed decisions. Analyzing raw data manually can make it difficult to identify trends, compare product performance, and understand inventory requirements.

### Goal of the Dashboard

The goal of this dashboard is to transform raw fruit sales and inventory data into meaningful visual insights. It provides a structured way to explore sales performance, understand product-level trends, and support effective business planning.

### Walkthrough of Key Visuals

- **Sales Overview:** Provides an overview of sales performance using the metrics available in the dataset.
- **Fruit-Wise Analysis:** Helps compare sales performance across different fruit products.
- **Inventory Analysis:** Supports the exploration of stock levels and inventory availability.
- **Sales Trends:** Helps identify patterns and changes in sales over time, if date information is available.
- **Interactive Filters:** Allow users to explore specific products or categories, depending on the dashboard design.

### Business Impact & Insights

- **Inventory Management:** Helps users understand stock availability and plan inventory more effectively.
- **Sales Analysis:** Supports comparisons of product sales performance.
- **Business Planning:** Helps identify useful patterns for operational planning.
- **Data-Driven Decisions:** Presents information visually to make analysis easier to understand.
